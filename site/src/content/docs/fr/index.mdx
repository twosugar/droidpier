markdownSummary: |
  Droidpier affiche l’émulateur Android officiel, qui tourne sur votre propre Mac, dans un onglet Chrome ou Edge. Un petit programme local, la passerelle, envoie l’écran de l’émulateur à la page via 127.0.0.1 et renvoie vos appuis, balayages et frappes au clavier.

  Configuration requise : un Mac avec Apple Silicon, Chrome ou Edge, et l’émulateur Android avec une image système arm64. Voir [Configuration requise](/fr/docs/getting-started/requirements/).

  Démarrez en deux étapes :

  1. Exécutez ceci dans Terminal : `curl -fsSL https://droid.devpier.dev/install.sh | sh`. La commande installe ou met à jour droidpier, puis le démarre en arrière-plan. Vous pouvez fermer la fenêtre. Lancez `droidpier stop` pour l’arrêter.
  2. Ouvrez https://droid.devpier.dev/app/. La page se connecte d’elle-même. La première fois, quand Chrome demande si la page peut accéder à votre réseau local, cliquez sur Autoriser.

  Toutes les étapes : [Installation](/fr/docs/getting-started/install/).
