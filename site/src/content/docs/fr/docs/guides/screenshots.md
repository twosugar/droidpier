## Faire une capture d’écran

Cliquez sur le bouton de capture d’écran au-dessus de l’écran. Votre navigateur télécharge un fichier PNG.

- L’image est prise depuis l’émulateur à la résolution propre de l’appareil, et non à la taille affichée dans la page. Pour un appareil en 1080×2340, le PNG fait 1080×2340.
- Le fichier est nommé `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, par exemple `screenshot-Pixel_5_API_34-20261111-153000.png`.
- Le fichier est enregistré dans le dossier de téléchargement de votre navigateur.
