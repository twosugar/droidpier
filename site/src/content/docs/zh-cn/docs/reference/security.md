页面从 `droid.devpier.dev` 提供，但模拟器和网关运行在你的 Mac 上。你打开的任何网页都可能尝试连接到你 Mac 上的程序，因此网关会检查每个连接。

## 仅限回环地址

网关仅在 `127.0.0.1` 上监听。它不接受来自本地网络或互联网的连接。其他计算机无法访问它。

## 来源白名单

<!-- verify: phase 3 -->
当页面打开 WebSocket 时，浏览器会发送 `Origin` 头，网页无法伪造它。网关只接受来自 `droid.devpier.dev` 上的公共页面及其自身本地页面的连接，即只接受以下来源：

- `https://droid.devpier.dev`
- `http://127.0.0.1:<port>`
- `http://localhost:<port>`

<!-- verify: phase 3 -->
来源不在列表中或无来源的连接会以代码 `4003` 关闭。其他网站的页面无法控制你的模拟器，即使猜到了端口。

## 页面如何找到网关

<!-- verify: phase 3 -->
- 在没有网关响应时，`droid.devpier.dev/app/` 上的页面每秒检查一次网关，`droidpier` 一运行就会连接。标签页在后台时，它不会检查。
- 它使用端口 `7300`，或地址中 `#port=` 之后的端口。只有当网关不在端口 `7300` 上运行时，网关才会在它打开的地址后附加 `#port=<port>`。
- 页面不会在浏览器中存储端口。

## 网站不会连接到你的 Mac

<!-- verify: phase 3 -->
Chrome 的本地网络权限和网关的来源检查都是基于站点而非路径的。因此文档页面与 `/app/` 上的模拟器页面共享同一权限。为限制其影响：

- 只有 `/app/` 上的模拟器页面才会连接到网关。首页和这些文档页面不会连接，因此阅读它们不会触发权限提示。
- 该网站不加载任何第三方脚本、样式、字体或媒体。所有内容均从 `droid.devpier.dev` 提供。

## 安装软件

<!-- verify: phase 3 -->
网关在未经询问的情况下，不会安装 Android SDK 包或创建设备。每次安装或新建设备，都由你在页面上确认，确认前页面会显示要下载什么、装到哪里。页面会完整显示 Google 的许可证，你同意后才会安装该项。23 及以上版本的命令行工具可能不询问就接受许可证；页面会在你确认前告诉你。网关不会在终端中提问。

## 连接关闭代码

<!-- verify: phase 3 -->
| 代码 | 含义 |
|---|---|
| `4000` | 第一条消息不是 `hello`。 |
| `4002` | 页面和网关使用不同的协议版本。 |
| `4003` | 来源不被允许。 |
