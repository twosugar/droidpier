## 鼠标与触控板

- **轻触：** 点击屏幕。
- **滑动：** 按下、拖动、松开。网关将此移动作为一次触摸发送给模拟器。
- 如果你拖动超出屏幕边缘并在屏幕外松开，模拟器仍会收到松开事件，触摸不会保持按压状态。

页面坐标会转换为设备像素，并考虑页面尺寸。

<!-- verify: phase 2 -->
旋转设备后，转换使用新的方向，因此点击位置与你点击的位置一致。

## 滚轮

<!-- verify: phase 2 -->
模拟器没有滚轮输入，因此页面将滚轮移动转换为短距离滑动：

- 每 100 像素的滚轮移动转换为设备上 300 像素的滑动，每次滑动最多 900 像素。
- 滑动方向与滚轮方向相反：向下滚动会使手指向上移动，就像在手机上一样。
- 50 ms 内的滚轮事件会合并为一次滑动。

## 键盘

先点击屏幕获得键盘焦点。

- 可打印字符和功能键（方向键、Enter、Backspace、Tab、Escape 等）在你按下时发送给模拟器。
- 使用 Cmd 的浏览器快捷键（如 Cmd+R 和 Cmd+W）不会被捕获，仍会作用于浏览器。

<!-- verify: phase 2 -->
Cmd+V 粘贴 Mac 上的内容。请参阅[剪贴板](/zh-cn/docs/guides/clipboard/)。

## 中文及其他非 ASCII 文字 {#chinese-and-other-non-ascii-text}

使用任何 macOS 输入法输入。当输入法完成词语组合后，页面会：

1. 将文字放入模拟器的剪贴板；
2. 向模拟器发送粘贴操作。

模拟器上不安装输入法应用。代价是：此操作会覆盖模拟器的剪贴板。

模拟器的按键输入会丢弃非 ASCII 字符，因此这类文字通过剪贴板传输。

## 设备按钮

屏幕上方的按钮：

| 按钮 | 发送 |
|---|---|
| 返回 | `GoBack` |
| 主页 | `GoHome` |
| 最近任务 | `AppSwitch` |

<!-- verify: phase 2 -->
| 按钮 | 操作 |
|---|---|
| 旋转 | 顺时针旋转设备 90° |
| 音量加 / 音量减 | `AudioVolumeUp` / `AudioVolumeDown` |
| 电源 | `Power`；再按一次唤醒屏幕 |
| 截图 | 下载 PNG 文件。请参阅[截图](/zh-cn/docs/guides/screenshots/) |
