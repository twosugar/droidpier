除了 Android 虚拟设备，页面还可以显示用 USB 线插在 Mac 上的真实 Android 手机。页面仍然每次只显示一个设备：手机或模拟器。

## 你需要什么

- 一根能传输数据的 USB 线，不能只支持充电。
- Android 5.0（API 21）或更高版本。这是内置的 scrcpy 服务端的要求。
- 在手机的开发者选项中打开 USB 调试。
- 第一次插上手机时，手机会询问是否允许这台 Mac 使用 USB 调试。请选择允许。
- Mac 上的 `platform-tools`（`adb`）。手机既不需要模拟器，也不需要系统镜像。请参阅[前置要求](/zh-cn/docs/getting-started/requirements/)。

## 手机列表

手机显示在设备列表中，单独成组，位于虚拟设备下方。每一行显示手机的厂商和型号、Android 版本以及状态：

- **可用**：点击该行即可切换到这部手机。
- **未授权**：手机还没有允许这台 Mac。请在手机上允许 USB 调试。
- **离线**：adb 能看到手机，但无法与它通信。请拔掉再重新插上。

没有插手机时，该分组会提示你插上手机并打开 USB 调试。

## 切换到手机

插上手机不会让页面自动切换过去：你可能只是想给手机充电。要切换，请点击列表中的手机。随后网关会通过 adb 把 scrcpy 服务端复制到手机上并启动它。服务端负责传送画面和接收输入。连接结束时，它会把自己从手机上删除，手机上不会留下任何东西。

页面显示手机期间，手机屏幕会保持常亮。

## 可以做什么

页面操作手机的方式与操作模拟器相同：

- 画面，缩放后长边最长为 1920 像素；
- 点击和拖动、滚轮和触控板滚动（作为真实的滚动事件发送到手机）、输入文字，包括中文（中文等非 ASCII 文字需要 Android 7.0 及以上）；
- 双向剪贴板；
- 返回、主页、最近任务、音量和电源；
- 截图，使用手机的完整分辨率；
- 把 APK 或文件拖到画面上来安装或复制；
- WebView 页面的 H5 调试；
- 日志面板；
- 浏览器中的 AI 工具。

## 有什么不同

- **旋转**跟随手机本身，没有旋转键。
- **没有停止键**：页面无法关闭手机。
- **重启**会在你确认后重启手机。页面会显示手机正在重启，待手机启动完成后自动重新连接，通常在一分钟内。如果手机有锁屏，请在页面上解锁。
- **拔掉**手机后，页面会显示手机已断开。重新插上，页面会自动重新连接。
- **状态行**显示帧率，但不显示延迟。手机的时钟与 Mac 的时钟不一致，两者无法比较。

## 只用手机，不用模拟器

如果你只用手机，只需要 `platform-tools`。装好它之后，只要还没有虚拟设备，即使缺少模拟器和系统镜像，页面也不会自动显示「环境检查」。之后想设置模拟器时，点击空设备列表下方的「安装模拟器（缺 N 项）」按钮，它会打开「环境检查」，在那里安装缺少的项。

没有 `platform-tools` 时，「真机」分组会提示你先在「环境检查」里安装它。
