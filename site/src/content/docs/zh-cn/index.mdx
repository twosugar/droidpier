markdownSummary: |
  Droidpier 让官方 Android 模拟器在你自己的 Mac 上运行，并在 Chrome 或 Edge 标签页中显示。一个小型本地程序（网关）通过 127.0.0.1 将模拟器画面发送到页面，并将你的点击、滑动和按键回传。

  前置要求：Apple Silicon Mac、Chrome 或 Edge，以及带有 arm64 系统镜像的 Android 模拟器。请参阅[前置要求](/zh-cn/docs/getting-started/requirements/)。

  两步即可开始：

  1. 在终端中运行以下命令：`curl -fsSL https://droid.devpier.dev/install.sh | sh`。它会安装或更新 droidpier，并在后台启动它。之后可以关闭窗口。运行 `droidpier stop` 停止。
  2. 打开 https://droid.devpier.dev/app/。页面会自行连接。首次打开时，当 Chrome 询问是否允许该页面访问你的本地网络时，点击允许。

  完整步骤：[安装](/zh-cn/docs/getting-started/install/)。
