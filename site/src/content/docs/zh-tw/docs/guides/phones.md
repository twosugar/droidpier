除了 Android 虛擬裝置，頁面也能顯示用 USB 線接到 Mac 上的真實 Android 手機。頁面仍然每次顯示一個裝置：手機或模擬器。

## 你需要什麼

- 一條能傳輸資料的 USB 線，不是只能充電的線。
- Android 5.0（API 21）或更新版本。內建的 scrcpy 伺服器需要這個版本。
- 在手機的開發人員選項中開啟 USB 偵錯。
- 第一次接上手機時，手機會詢問是否允許這台 Mac 進行 USB 偵錯。請允許。
- Mac 上要有 `platform-tools`（`adb`）。手機既不需要模擬器，也不需要系統映像。請參閱[前置需求](/zh-tw/docs/getting-started/requirements/)。

## 手機清單

手機會顯示在裝置清單中自己的群組裡，位於虛擬裝置下方。每一列顯示手機的廠牌和型號、Android 版本與狀態：

- **可用**：點擊該列即可切換到手機。
- **未授權**：手機尚未允許這台 Mac。請在手機上允許 USB 偵錯。
- **離線**：adb 看得到手機，但無法與它通訊。請拔掉再重新接上。

沒有接上手機時，這個群組會提示你接上手機並開啟 USB 偵錯。

## 切換到手機

接上手機不會讓頁面自動切換過去，因為你可能只是在充電。請點擊清單中的手機來切換。閘道接著透過 adb 把 scrcpy 伺服器複製到手機上並啟動它。伺服器負責串流畫面並接收輸入。連線結束時，它會自行從手機上刪除，手機上不會留下任何已安裝的東西。

頁面顯示手機期間，手機螢幕會保持亮著。

## 可以做什麼

頁面操作手機的方式和操作模擬器相同：

- 畫面，縮放後長邊最多 1920 像素；
- 點擊與拖曳、滾輪和觸控板捲動（以真實的捲動事件傳給手機），以及輸入文字，包括中文（中文等非 ASCII 文字需要 Android 7.0 以上）；
- 雙向剪貼簿；
- 返回、首頁、最近使用、音量和電源；
- 截圖，使用手機的完整解析度；
- 把 APK 或檔案拖放到畫面上來安裝或複製；
- WebView 頁面的 H5 偵錯；
- 記錄面板；
- 瀏覽器中的 AI 工具。

## 有哪些不同

- **旋轉**跟隨手機本身。沒有旋轉鍵。
- **沒有停止鍵**：頁面無法替手機關機。
- **重新啟動**會在你確認後重新啟動手機。頁面會顯示手機正在重新啟動，等手機開機完成後會自動重新連線，通常在一分鐘內。如果手機有鎖定畫面，請在頁面上解鎖。
- **拔掉**手機時，頁面會顯示手機已中斷連線。重新接上後，頁面會自動重新連線。
- **狀態列**顯示影格率，但不顯示延遲。手機的時鐘和 Mac 不同，所以兩者無法比較。

## 只用手機，不用模擬器

只用手機的話，只需要 `platform-tools`。安裝之後，只要你還沒有虛擬裝置，頁面就不會自動顯示「環境檢查」，即使缺少模擬器和系統映像。之後想設定模擬器時，請點擊空裝置清單下方的「安装模拟器（缺 N 项）」按鈕，它會打開「環境檢查」，在那裡安裝缺少的項目。

沒有 `platform-tools` 時，「真機」分組會請你先在「環境檢查」裡安裝它。
