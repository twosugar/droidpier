## 截圖

點擊畫面上方的截圖按鈕。瀏覽器會下載一個 PNG 檔案。

- 影像從模擬器以裝置自身解析度擷取，而非頁面中顯示的尺寸。對於 1080×2340 的裝置，PNG 為 1080×2340。
- 檔案名稱為 `screenshot-<AVD 名稱>-<yyyyMMdd-HHmmss>.png`，例如 `screenshot-Pixel_5_API_34-20261111-153000.png`。
- 檔案儲存到瀏覽器的下載資料夾。
