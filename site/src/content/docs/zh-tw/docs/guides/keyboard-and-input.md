## 滑鼠與觸控板

- **輕觸：** 點擊畫面。
- **滑動：** 按下、拖曳、放開。閘道將此移動作為一次觸控傳送給模擬器。
- 如果你拖曳超出畫面邊緣並在畫面外放開，模擬器仍會收到放開事件，觸控不會保持按壓狀態。

頁面座標會轉換為裝置像素，並考量頁面尺寸。

<!-- verify: phase 2 -->
旋轉裝置後，轉換使用新的方向，因此點擊位置與你點擊的位置一致。

## 滾輪

<!-- verify: phase 2 -->
模擬器沒有滾輪輸入，因此頁面將滾輪移動轉換為短距離滑動：

- 每 100 像素的滾輪移動轉換為裝置上 300 像素的滑動，每次滑動最多 900 像素。
- 滑動方向與滾輪方向相反：向下滾動會使手指向上移動，就像在手機上一樣。
- 50 ms 內的滾輪事件會合併為一次滑動。

## 鍵盤

先點擊畫面取得鍵盤焦點。

- 可列印字元和功能鍵（方向鍵、Enter、Backspace、Tab、Escape 等）在你按下時傳送給模擬器。
- 使用 Cmd 的瀏覽器快速鍵（如 Cmd+R 和 Cmd+W）不會被擷取，仍會作用於瀏覽器。

<!-- verify: phase 2 -->
Cmd+V 貼上 Mac 上的內容。請參閱[剪貼簿](/zh-tw/docs/guides/clipboard/)。

## 中文及其他非 ASCII 文字 {#chinese-and-other-non-ascii-text}

使用任何 macOS 輸入法輸入。當輸入法完成詞語組合後，頁面會：

1. 將文字放入模擬器的剪貼簿；
2. 向模擬器傳送貼上操作。

模擬器上不安裝輸入法應用程式。代價是：此操作會覆蓋模擬器的剪貼簿。

模擬器的按鍵輸入會捨棄非 ASCII 字元，因此這類文字透過剪貼簿傳輸。

## 裝置按鈕

畫面上方的按鈕：

| 按鈕 | 傳送 |
|---|---|
| 返回 | `GoBack` |
| 首頁 | `GoHome` |
| 最近使用 | `AppSwitch` |

<!-- verify: phase 2 -->
| 按鈕 | 操作 |
|---|---|
| 旋轉 | 順時針旋轉裝置 90° |
| 音量加 / 音量減 | `AudioVolumeUp` / `AudioVolumeDown` |
| 電源 | `Power`；再按一次喚醒螢幕 |
| 截圖 | 下載 PNG 檔案。請參閱[截圖](/zh-tw/docs/guides/screenshots/) |
