頁面從 `droid.devpier.dev` 提供，但模擬器和閘道執行在你的 Mac 上。你開啟的任何網頁都可能嘗試連接到你 Mac 上的程式，因此閘道會檢查每個連線。

## 僅限回送位址

閘道僅在 `127.0.0.1` 上監聽。它不接受來自本機網路或網際網路的連線。其他電腦無法存取它。

## 來源允許清單

<!-- verify: phase 3 -->
當頁面開啟 WebSocket 時，瀏覽器會傳送 `Origin` 標頭，網頁無法偽造它。閘道只接受來自 `droid.devpier.dev` 上的公共頁面及其自身本機頁面的連線，即只接受以下來源：

- `https://droid.devpier.dev`
- `http://127.0.0.1:<port>`
- `http://localhost:<port>`

<!-- verify: phase 3 -->
來源不在清單中或無來源的連線會以代碼 `4003` 關閉。其他網站的頁面無法控制你的模擬器，即使猜到了連接埠。

## 頁面如何找到閘道

<!-- verify: phase 3 -->
- 在沒有閘道回應時，`droid.devpier.dev/app/` 上的頁面每秒檢查一次閘道，`droidpier` 一執行就會連線。分頁在背景時，它不會檢查。
- 它使用連接埠 `7300`，或位址中 `#port=` 之後的連接埠。只有當閘道不在連接埠 `7300` 上執行時，閘道才會在它開啟的位址後附加 `#port=<port>`。
- 頁面不會在瀏覽器中儲存連接埠。

## 網站不會連接到你的 Mac

<!-- verify: phase 3 -->
Chrome 的本機網路權限和閘道的來源檢查都是基於網站而非路徑的。因此文件頁面與 `/app/` 上的模擬器頁面共享同一權限。為限制其影響：

- 只有 `/app/` 上的模擬器頁面才會連接到閘道。首頁和這些文件頁面不會連接，因此閱讀它們不會觸發權限提示。
- 該網站不載入任何第三方腳本、樣式、字型或媒體。所有內容均從 `droid.devpier.dev` 提供。

## 安裝軟體

<!-- verify: phase 3 -->
閘道在未經詢問的情況下，不會安裝 Android SDK 套件或建立裝置。每次安裝或建立裝置，都由你在頁面上確認，確認前頁面會顯示要下載什麼、裝到哪裡。頁面會完整顯示 Google 的授權條款，你同意後才會安裝該項。23 以上版本的命令列工具可能不詢問就接受授權條款；頁面會在你確認前告訴你。閘道不會在終端機中提問。

## 連線關閉代碼

<!-- verify: phase 3 -->
| 代碼 | 含義 |
|---|---|
| `4000` | 第一條訊息不是 `hello`。 |
| `4002` | 頁面和閘道使用不同的協定版本。 |
| `4003` | 來源不被允許。 |
