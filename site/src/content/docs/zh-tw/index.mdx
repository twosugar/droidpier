markdownSummary: |
  Droidpier 讓官方 Android 模擬器在你自己的 Mac 上執行，並在 Chrome 或 Edge 分頁中顯示。一個小型本地程式（閘道）透過 127.0.0.1 將模擬器畫面傳送到頁面，並將你的點擊、滑動和按鍵回傳。

  前置需求：Apple Silicon Mac、Chrome 或 Edge，以及含有 arm64 系統映像的 Android 模擬器。請參閱[前置需求](/zh-tw/docs/getting-started/requirements/)。

  兩個步驟即可開始：

  1. 在終端機中執行以下命令，並保持該視窗開啟：`curl -fsSL https://droid.devpier.dev/install.sh | sh`。它會安裝或更新 droidpier，然後啟動它。按 Ctrl+C 停止。
  2. 開啟 https://droid.devpier.dev/app/。頁面會自行連線。第一次開啟時，當 Chrome 詢問是否允許該頁面存取你的本機網路時，點擊允許。

  完整步驟：[安裝](/zh-tw/docs/getting-started/install/)。
