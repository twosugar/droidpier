## Fare uno screenshot

Fai clic sul pulsante screenshot sopra lo schermo. Il tuo browser scarica un file PNG.

- L’immagine viene acquisita dall’emulatore alla risoluzione propria del dispositivo, non alla dimensione mostrata nella pagina. Per un dispositivo 1080×2340 il PNG è 1080×2340.
- Il file si chiama `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, ad esempio `screenshot-Pixel_5_API_34-20261111-153000.png`.
- Il file va nella cartella dei download del tuo browser.
