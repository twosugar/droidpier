## Mac에서 에뮬레이터로

<!-- verify: phase 2 -->
Mac에서 텍스트를 복사합니다. 에뮬레이터 화면을 클릭한 다음 Cmd+V를 누르세요:

- ASCII 텍스트는 에뮬레이터에 한 글자씩 입력됩니다.
- 그 밖의 문자(중국어, 이모지 등)가 포함된 텍스트는 에뮬레이터의 클립보드에 넣은 뒤 붙여 넣습니다. 이때 에뮬레이터 클립보드에 있던 내용은 대체됩니다.

## 에뮬레이터에서 Mac으로

<!-- verify: phase 2 -->
Android 안에서 텍스트를 복사합니다. 예를 들어 길게 누른 뒤 복사를 선택합니다. 게이트웨이는 에뮬레이터의 클립보드를 감시하다가 새 텍스트를 페이지로 보냅니다. 그러면 페이지가 이를 Mac의 클립보드에 쓰고, Mac 어디서든 Cmd+V로 붙여 넣을 수 있습니다.

<!-- verify: phase 2 -->
브라우저는 페이지에 포커스가 있을 때만 클립보드 쓰기를 허용합니다. 예를 들어 다른 창이 앞에 있어서 쓰기에 실패하면 페이지에 알림이 표시됩니다. 알림을 클릭하면 텍스트가 복사됩니다.

## 비ASCII 텍스트 입력

macOS 입력기로 중국어나 기타 비ASCII 텍스트를 입력할 때도 에뮬레이터의 클립보드를 사용합니다. [키보드와 입력](/ko/docs/guides/keyboard-and-input/#chinese-and-other-non-ascii-text)을 참고하세요.
