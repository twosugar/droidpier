## 마우스와 트랙패드

- **탭:** 화면을 클릭합니다.
- **스와이프:** 누르고, 드래그하고, 놓습니다. 게이트웨이는 이 움직임을 하나의 터치로 에뮬레이터에 보냅니다.
- 화면 가장자리를 넘어 드래그한 뒤 화면 밖에서 놓아도 에뮬레이터는 놓기 동작을 받으므로, 터치가 눌린 채로 남지 않습니다.

페이지 좌표는 페이지 크기를 고려해 기기 픽셀로 변환됩니다.

<!-- verify: phase 2 -->
기기를 회전하면 변환에 새 방향이 적용되므로, 탭은 클릭한 위치에 정확히 들어갑니다.

## 스크롤 휠

<!-- verify: phase 2 -->
에뮬레이터에는 스크롤 휠 입력이 없으므로, 페이지가 휠 움직임을 짧은 스와이프로 바꿉니다:

- 휠 움직임 100픽셀마다 기기에서 300픽셀 스와이프가 되며, 스와이프 한 번에 최대 900픽셀입니다.
- 스와이프는 휠과 반대 방향으로 움직입니다. 휴대폰에서처럼 아래로 스크롤하면 손가락이 위로 움직입니다.
- 50 ms 안에 발생한 휠 이벤트는 하나의 스와이프로 합쳐집니다.

## 키보드

먼저 화면을 클릭하세요. 그러면 화면에 키보드 포커스가 생깁니다.

- 출력 가능한 문자와 기능 키(화살표, Enter, Backspace, Tab, Escape 등)는 누르는 대로 에뮬레이터로 전송됩니다.
- Cmd+R, Cmd+W처럼 Cmd를 사용하는 브라우저 단축키는 가로채지 않습니다. 이 단축키는 그대로 브라우저에 작용합니다.

<!-- verify: phase 2 -->
Cmd+V는 Mac에서 붙여 넣습니다. [클립보드](/ko/docs/guides/clipboard/)를 참고하세요.

## 중국어 및 기타 비ASCII 텍스트 {#chinese-and-other-non-ascii-text}

아무 macOS 입력기로나 입력하세요. 입력기가 단어 조합을 마치면 페이지는:

1. 텍스트를 에뮬레이터의 클립보드에 넣고,
2. 에뮬레이터에 붙여넣기를 보냅니다.

에뮬레이터에는 입력기 앱을 설치하지 않습니다. 대신 에뮬레이터의 클립보드를 덮어쓴다는 단점이 있습니다.

에뮬레이터의 키 입력은 비ASCII 문자를 버리기 때문에 이 텍스트는 클립보드를 거칩니다.

## 기기 버튼

화면 위의 버튼:

| 버튼 | 전송하는 키 |
|---|---|
| 뒤로 | `GoBack` |
| 홈 | `GoHome` |
| 최근 앱 | `AppSwitch` |

<!-- verify: phase 2 -->
| 버튼 | 동작 |
|---|---|
| 회전 | 기기를 시계 방향으로 90° 회전합니다 |
| 볼륨 크게 / 작게 | `AudioVolumeUp` / `AudioVolumeDown` |
| 전원 | `Power`. 다시 누르면 화면이 다시 켜집니다 |
| 스크린샷 | PNG를 다운로드합니다. [스크린샷](/ko/docs/guides/screenshots/)을 참고하세요 |
