## 스크린샷 찍기

화면 위의 스크린샷 버튼을 클릭하세요. 브라우저가 PNG 파일을 다운로드합니다.

- 이미지는 페이지에 표시된 크기가 아니라 기기 자체 해상도로 에뮬레이터에서 가져옵니다. 1080×2340 기기라면 PNG도 1080×2340입니다.
- 파일 이름은 `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png` 형식입니다. 예: `screenshot-Pixel_5_API_34-20261111-153000.png`.
- 파일은 브라우저의 다운로드 폴더에 저장됩니다.
