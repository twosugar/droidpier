## Einen Screenshot aufnehmen

Klicken Sie auf die Screenshot-Taste über dem Bildschirm. Ihr Browser lädt eine PNG-Datei herunter.

- Das Bild wird vom Emulator in der eigenen Auflösung des Geräts aufgenommen, nicht in der Größe, die in der Seite angezeigt wird. Bei einem Gerät mit 1080×2340 ist das PNG 1080×2340 groß.
- Die Datei heißt `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, zum Beispiel `screenshot-Pixel_5_API_34-20261111-153000.png`.
- Die Datei landet im Download-Ordner Ihres Browsers.
