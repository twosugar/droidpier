## С Mac в эмулятор

<!-- verify: phase 2 -->
Скопируйте текст на Mac. Щёлкните по экрану эмулятора и нажмите Cmd+V:

- Текст ASCII вводится в эмулятор посимвольно.
- Текст с другими символами (китайский, эмодзи и т. п.) помещается в буфер обмена эмулятора и вставляется. При этом прежнее содержимое буфера обмена эмулятора заменяется.

## Из эмулятора на Mac

<!-- verify: phase 2 -->
Скопируйте текст внутри Android, например долгим нажатием и выбором «Копировать». Шлюз следит за буфером обмена эмулятора и отправляет новый текст на страницу. Затем страница записывает его в буфер обмена Mac, и вы можете вставить его с помощью Cmd+V в любом месте на Mac.

<!-- verify: phase 2 -->
Браузеры разрешают странице записывать в буфер обмена, только пока страница в фокусе. Если запись не удалась, например потому что поверх было другое окно, страница показывает уведомление. Щёлкните по нему, чтобы скопировать текст.

## Ввод текста не в ASCII

Ввод китайского или другого текста не в ASCII с помощью метода ввода macOS тоже использует буфер обмена эмулятора. См. [Клавиатура и ввод](/ru/docs/guides/keyboard-and-input/#chinese-and-other-non-ascii-text).
