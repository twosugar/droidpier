Устройство здесь — это Android Virtual Device (AVD) на вашем Mac. Страница показывает одно устройство за раз.

## Список устройств

<!-- verify: phase 2 -->
Список слева показывает каждый AVD, который выдаёт `emulator -list-avds`. Для каждого указаны:

- имя;
- разрешение экрана;
- версия Android;
- состояние: не запущено, загружается (с числом прошедших секунд), запущено или запущено, но не может быть взято под управление;
- кнопка запуска или остановки.

<!-- verify: phase 2 -->
Разрешение, RAM и версия Android берутся из `config.ini` каждого AVD в `~/.android/avd/<name>.avd/`. Если вы задали `ANDROID_AVD_HOME`, шлюз читает этот каталог. Если поля нет в `config.ini`, оно остаётся пустым.

## Запуск устройства

<!-- verify: phase 2 -->
Нажмите «Запустить» рядом с устройством. Шлюз выполняет:

```sh
emulator -avd <name> -no-window -grpc <port> -no-boot-anim -gpu host
```

- `-no-window` означает, что отдельное окно эмулятора не открывается. Экран появляется только на странице.
- Порт gRPC — первый свободный чётный порт начиная с `8554`.
- Устройство считается загруженным, когда `adb -s emulator-<serial> shell getprop sys.boot_completed` возвращает `1`. До этого страница показывает ход загрузки.
- Если устройство не загрузилось за 180 секунд, запуск завершается ошибкой, и шлюз завершает процесс эмулятора.

<!-- verify: phase 2 -->
Повторное нажатие «Запустить» во время загрузки устройства не запускает вторую копию. Если закрыть страницу во время загрузки и открыть её снова, ход загрузки продолжится.

## Остановка устройства

<!-- verify: phase 2 -->
Нажмите «Остановить». Шлюз выполняет `adb -s emulator-<serial> emu kill`.

## Уже запущенные эмуляторы

Шлюз находит запущенные эмуляторы по файлам, которые эмулятор записывает в `~/Library/Caches/TemporaryItems/avd/running/`. Если эмулятор запущен с включённым gRPC, например вы запустили его с `-grpc <port>`, шлюз подключается к нему вместо запуска ещё одной копии.

<!-- verify: phase 2 -->
Эмулятор, работающий без gRPC, помечается как «запущено, но не может быть взято под управление». Шлюзу нужен gRPC, чтобы читать экран и отправлять ввод. Остановите такой эмулятор и запустите его со страницы.

## Когда шлюз останавливается

Остановка шлюза не останавливает эмуляторы. Когда вы снова запустите шлюз, он снова подключится к ним.

## Создание устройства

<!-- verify: phase 3 -->
Устройства создаются на странице. Нажмите кнопку нового устройства, выберите модель устройства и версию Android и задайте имя устройства; страница предложит его сама. Перед созданием страница показывает модель, версию Android и объём памяти устройства. Если системный образ этой версии ещё не установлен, шлюз скачает его после вашего подтверждения и согласия с лицензией Google.

Для создания устройства нужны инструменты командной строки (`avdmanager`). Если их нет, окно сначала предложит их установить. См. [Первый запуск](/ru/docs/getting-started/first-run/#2-let-it-check-your-android-sdk).

Устройства можно создавать и через `avdmanager` или Android Studio — список их увидит.
