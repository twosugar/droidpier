## Сделать снимок экрана

Нажмите кнопку снимка экрана над экраном. Браузер скачает PNG-файл.

- Изображение снимается с эмулятора в собственном разрешении устройства, а не в размере, показанном на странице. Для устройства 1080×2340 PNG будет 1080×2340.
- Файл называется `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, например `screenshot-Pixel_5_API_34-20261111-153000.png`.
- Файл сохраняется в папку загрузок вашего браузера.
