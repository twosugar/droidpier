```sh
droidpier start [--port <port>] [--local] [--no-open] [--no-auto-update]
droidpier stop
droidpier status
droidpier logs
droidpier [--port <port>] [--local] [--no-open]
```

| Команда | Что делает |
|---|---|
| `droidpier start` | Запускает шлюз в фоновом режиме как LaunchAgent macOS. Он продолжает работать после закрытия Терминала, запускается при входе в систему и перезапускается после сбоя. Если шлюз уже работает, перезапускает его. Сохраняет переданные параметры; без параметров оставляет сохранённые. Один раз открывает страницу, если не указан `--no-open`. Кроме того, он сам обновляется: см. [Автоматические обновления](#automatic-updates). |
| `droidpier stop` | Останавливает фоновый шлюз. При входе в систему он больше не запускается. |
| `droidpier status` | Показывает, работает ли фоновый шлюз, с ID процесса, портом, версией и файлом журнала. Также показывает, включены ли автоматические обновления, и результат последней проверки. |
| `droidpier logs` | Выводит путь к файлу журнала и его последние 50 строк. |
| `droidpier` | Запускает шлюз в этом окне Терминала до нажатия `Ctrl+C`. |

Остановка шлюза не останавливает запущенные эмуляторы.

## Запуск командой установки {#start-with-the-install-command}

Команда установки `curl -fsSL https://droid.devpier.dev/install.sh | sh` устанавливает или обновляет шлюз, а затем выполняет `droidpier start`. Чтобы передать параметры, укажите их после `sh -s --`. Они сохраняются для фонового шлюза:

```sh
curl -fsSL https://droid.devpier.dev/install.sh | sh -s -- --port 7310
```

Чтобы установить или обновить шлюз без запуска, задайте `DROIDPIER_NO_START=1`:

```sh
curl -fsSL https://droid.devpier.dev/install.sh | DROIDPIER_NO_START=1 sh
```

Чтобы, как раньше, запустить шлюз в окне Терминала, задайте `DROIDPIER_FOREGROUND=1`:

```sh
curl -fsSL https://droid.devpier.dev/install.sh | DROIDPIER_FOREGROUND=1 sh
```

## Параметры

| Параметр | По умолчанию | Действие |
|---|---|---|
| `--port <port>` | `7300` | Порт, который слушает шлюз, только на `127.0.0.1`. |

<!-- verify: phase 3 -->
| Параметр | По умолчанию | Действие |
|---|---|---|
| `--local` | выключен | Открывать страницу, которую отдаёт сам шлюз, `http://127.0.0.1:<port>/app/`, вместо публичной страницы на `droid.devpier.dev`. |
| `--no-open` | выключен | Не открывать браузер при запуске. Шлюз всё равно выводит адрес. |
| `--no-auto-update` | выключен | Для `droidpier start`: не обновлять фоновый шлюз автоматически. В терминале: не выводить строку, когда вышла новая версия. |

С `--no-open` или без него страница находит шлюз сама. См. [Первый запуск](/ru/docs/getting-started/first-run/#3-open-the-page).

## Переменные окружения

| Переменная | Действие |
|---|---|
| `ANDROID_HOME` | Каталог Android SDK. Без неё шлюз использует `~/Library/Android/sdk`. |
| `ANDROID_AVD_HOME` | Каталог, в котором хранятся AVD. Без неё шлюз использует `avd` внутри `ANDROID_USER_HOME`, если там есть AVD, иначе `~/.android/avd`. Шлюз передаёт результат эмуляторам, которые запускает. |
| `ANDROID_USER_HOME` | Пользовательский каталог Android. Без неё шлюз использует `~/.android`. |
| `DEBUG=1` | Раз в секунду выводить по строке для каждого подключения: полученные, отправленные и отброшенные кадры, средний размер кадра и задержку от эмулятора до шлюза. |

<!-- verify: phase 2 -->
`ANDROID_AVD_HOME` читается, когда шлюз получает список устройств.

<!-- verify: phase 3 -->
`ANDROID_HOME` читается проверкой при первом запуске.

Если заданы `ANDROID_HOME`, `ANDROID_AVD_HOME` и `ANDROID_USER_HOME`, `droidpier start` сохраняет их для фонового шлюза, потому что launchd не читает профиль вашей оболочки. После их изменения снова выполните `droidpier start`.

## Что он выводит

При запуске шлюз выводит адрес страницы. Если ни один эмулятор не запущен, он выводит причину и продолжает работать.

<!-- verify: phase 3 -->
По умолчанию выводится адрес публичной страницы, `https://droid.devpier.dev/app/`. Если шлюз работает не на порту `7300`, адрес заканчивается на `#port=<port>`. С `--local` это адрес локальной страницы, `http://127.0.0.1:<port>/app/`. Шлюз открывает адрес командой macOS `open`, если вы не передали `--no-open`.

Если на порту уже работает шлюз, второй не запускается. Он сообщает, что droidpier уже работает, указывает порт и открывает страницу. Если работает фоновый шлюз, он также выводит `droidpier stop`. Если порт занят другой программой, он сообщает об этом, предлагает другой порт и завершается.

<!-- verify: phase 3 -->
Если не хватает частей Android SDK, шлюз выводит каждую с командой для ручной установки и предлагает завершить настройку на странице. В Терминале он никогда ничего не спрашивает: установку, новые устройства и лицензии вы подтверждаете на странице. См. [Первый запуск](/ru/docs/getting-started/first-run/#2-let-it-check-your-android-sdk).

## Автоматические обновления {#automatic-updates}

Фоновый шлюз сам поддерживает себя в актуальном состоянии. При запуске и затем примерно каждые 30 минут он сравнивает контрольную сумму опубликованной версии с контрольной суммой установленной (`~/.local/share/droidpier/installed.sha256`). Когда выходит новая версия, он скачивает её с `droid.devpier.dev`, проверяет контрольную сумму до распаковки, заменяет `~/.local/bin/droidpier` и перезапускается. Открытые страницы переподключаются сами. Пока идёт установка SDK, запуск устройства, удаление устройства, перезапуск эмулятора или передача файла, он ждёт. Если загрузка не удалась или контрольная сумма не совпала, он продолжает работать на текущей версии и пробует позже. Каждый шаг записывается в журнал (`droidpier logs`).

Когда страница видит, что фоновый шлюз старее неё, она просит шлюз проверить обновления сразу и показывает, что шлюз обновляется.

Чтобы выключить автоматические обновления, выполните `droidpier start --no-auto-update`. Чтобы включить их снова, выполните `droidpier start` с остальными параметрами и без `--no-auto-update`, например `droidpier start --port 7300`. `droidpier status` показывает, включены ли они.

Шлюз, запущенный в окне терминала (`droidpier`), не заменяет себя сам. Когда есть новая версия, он выводит одну строку: выполните `droidpier start`, чтобы перейти на фоновый шлюз, который обновляется сам, или снова выполните команду установки.

## Удаление {#uninstall}

Остановите фоновый шлюз, затем удалите файлы, которые он использует:

```sh
droidpier stop
rm ~/.local/bin/droidpier
rm -r ~/.local/share/droidpier ~/Library/Logs/Droidpier
```

Если `droidpier` уже удалён, а фоновый шлюз всё ещё работает или запускается при входе в систему, удалите его вручную:

```sh
launchctl bootout gui/$(id -u)/dev.devpier.droidpier
rm ~/Library/LaunchAgents/dev.devpier.droidpier.plist
```
