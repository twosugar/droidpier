```sh
droidpier start [--port <port>] [--local] [--no-open]
droidpier stop
droidpier status
droidpier logs
droidpier [--port <port>] [--local] [--no-open]
```

| Команда | Что делает |
|---|---|
| `droidpier start` | Запускает шлюз в фоновом режиме как LaunchAgent macOS. Он продолжает работать после закрытия Терминала, запускается при входе в систему и перезапускается после сбоя. Если шлюз уже работает, перезапускает его. Сохраняет переданные параметры; без параметров оставляет сохранённые. Один раз открывает страницу, если не указан `--no-open`. |
| `droidpier stop` | Останавливает фоновый шлюз. При входе в систему он больше не запускается. |
| `droidpier status` | Показывает, работает ли фоновый шлюз, с ID процесса, портом, версией и файлом журнала. |
| `droidpier logs` | Выводит путь к файлу журнала и его последние 50 строк. |
| `droidpier` | Запускает шлюз в этом окне Терминала до нажатия `Ctrl+C`. |

Остановка шлюза не останавливает запущенные эмуляторы.

## Запуск командой установки {#start-with-the-install-command}

Команда установки `curl -fsSL https://droid.devpier.dev/install.sh | sh` устанавливает или обновляет шлюз, а затем выполняет `droidpier start`. Чтобы передать параметры, укажите их после `sh -s --`. Они сохраняются для фонового шлюза:

```sh
curl -fsSL https://droid.devpier.dev/install.sh | sh -s -- --port 7310
```

Чтобы установить или обновить шлюз без запуска, задайте `DROIDPIER_NO_START=1`:

```sh
curl -fsSL https://droid.devpier.dev/install.sh | DROIDPIER_NO_START=1 sh
```

Чтобы, как раньше, запустить шлюз в окне Терминала, задайте `DROIDPIER_FOREGROUND=1`:

```sh
curl -fsSL https://droid.devpier.dev/install.sh | DROIDPIER_FOREGROUND=1 sh
```

## Параметры

| Параметр | По умолчанию | Действие |
|---|---|---|
| `--port <port>` | `7300` | Порт, который слушает шлюз, только на `127.0.0.1`. |

<!-- verify: phase 3 -->
| Параметр | По умолчанию | Действие |
|---|---|---|
| `--local` | выключен | Открывать страницу, которую отдаёт сам шлюз, `http://127.0.0.1:<port>/app/`, вместо публичной страницы на `droid.devpier.dev`. |
| `--no-open` | выключен | Не открывать браузер при запуске. Шлюз всё равно выводит адрес. |

С `--no-open` или без него страница находит шлюз сама. См. [Первый запуск](/ru/docs/getting-started/first-run/#3-open-the-page).

## Переменные окружения

| Переменная | Действие |
|---|---|
| `ANDROID_HOME` | Каталог Android SDK. Без неё шлюз использует `~/Library/Android/sdk`. |
| `ANDROID_AVD_HOME` | Каталог, в котором хранятся AVD. Без неё шлюз использует `~/.android/avd`. |
| `DEBUG=1` | Раз в секунду выводить по строке для каждого подключения: полученные, отправленные и отброшенные кадры, средний размер кадра и задержку от эмулятора до шлюза. |

<!-- verify: phase 2 -->
`ANDROID_AVD_HOME` читается, когда шлюз получает список устройств.

<!-- verify: phase 3 -->
`ANDROID_HOME` читается проверкой при первом запуске.

Если заданы `ANDROID_HOME` и `ANDROID_AVD_HOME`, `droidpier start` сохраняет их для фонового шлюза, потому что launchd не читает профиль вашей оболочки. После их изменения снова выполните `droidpier start`.

## Что он выводит

При запуске шлюз выводит адрес страницы. Если ни один эмулятор не запущен, он выводит причину и продолжает работать.

<!-- verify: phase 3 -->
По умолчанию выводится адрес публичной страницы, `https://droid.devpier.dev/app/`. Если шлюз работает не на порту `7300`, адрес заканчивается на `#port=<port>`. С `--local` это адрес локальной страницы, `http://127.0.0.1:<port>/app/`. Шлюз открывает адрес командой macOS `open`, если вы не передали `--no-open`.

Если на порту уже работает шлюз, второй не запускается. Он сообщает, что droidpier уже работает, указывает порт и открывает страницу. Если работает фоновый шлюз, он также выводит `droidpier stop`. Если порт занят другой программой, он сообщает об этом, предлагает другой порт и завершается.

<!-- verify: phase 3 -->
Если не хватает частей Android SDK, шлюз выводит каждую с командой для ручной установки и предлагает завершить настройку на странице. В Терминале он никогда ничего не спрашивает: установку, новые устройства и лицензии вы подтверждаете на странице. См. [Первый запуск](/ru/docs/getting-started/first-run/#2-let-it-check-your-android-sdk).

## Используемые файлы и порты

| Что | Где |
|---|---|
| Адрес, который слушает шлюз | `127.0.0.1:<port>` |
| Обнаружение запущенных эмуляторов | `~/Library/Caches/TemporaryItems/avd/running/pid_<pid>.ini` |

<!-- verify: phase 2 -->
| Что | Где |
|---|---|
| Назначаемые порты gRPC эмулятора | Первый свободный чётный порт начиная с `8554` |

<!-- verify: phase 3 -->
| Что | Где |
|---|---|
| Установленный исполняемый файл | `~/.local/bin/droidpier` |
| Контрольная сумма установленной версии | `~/.local/share/droidpier/installed.sha256` |
| Настройки фонового шлюза | `~/Library/LaunchAgents/dev.devpier.droidpier.plist` |
| Журнал фонового шлюза | `~/Library/Logs/Droidpier/droidpier.log` |
