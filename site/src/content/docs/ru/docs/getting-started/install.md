Начать работу можно за два шага:

1. Выполните команду ниже в Терминале. Она установит Droidpier и запустит его в фоновом режиме.
2. Откройте `https://droid.devpier.dev/app/`. Страница подключится сама. В первый раз, когда Chrome спросит, может ли страница получить доступ к вашей локальной сети, нажмите **Разрешить**.

Шаг 2 описан в разделе [Первый запуск](/ru/docs/getting-started/first-run/).

<!-- verify: phase 3 -->
Команда `droidpier` — это шлюз: один исполняемый файл, который связывает эмулятор Android на вашем Mac со страницей в браузере. Для его запуска Node.js не нужен.

## Выполните команду

<!-- verify: phase 3 -->

Сначала проверьте [требования](/ru/docs/getting-started/requirements/). Затем выполните в Терминале:

<!-- 待第 3 阶段 Task 5 确认 -->
```sh
curl -fsSL https://droid.devpier.dev/install.sh | sh
```

При первом запуске скрипт:

1. Скачивает шлюз для macOS на Apple Silicon, `droidpier-darwin-arm64.tar.xz`, с `https://droid.devpier.dev/download/`. Его контрольная сумма лежит рядом, в `droidpier-darwin-arm64.tar.xz.sha256`.
2. Сверяет загруженный файл с контрольной суммой. Если они не совпадают, скрипт останавливается и ничего не устанавливает.
3. Сохраняет шлюз как `~/.local/bin/droidpier` и делает его исполняемым.
4. Запускает шлюз в фоновом режиме командой `droidpier start`.

Шлюз работает в фоновом режиме. Окно Терминала можно закрыть: шлюз продолжит работать и снова запустится при входе в систему. Чтобы остановить его, выполните `droidpier stop`; чтобы проверить состояние — `droidpier status`.

Если выполнить ту же команду снова:

- Если ваша копия актуальна, загрузка пропускается и шлюз перезапускается.
- Если есть более новая версия, копия обновляется, а шлюз перезапускается, чтобы заработала новая версия.
- Если сайт загрузки недоступен, он предупреждает об этом и запускает уже установленную копию.
- Если шлюз уже работает в каком-то окне Терминала, команда сообщает об этом и ничего не запускает. Сначала остановите его клавишами `Ctrl+C`.

Как передать шлюзу параметры или установить его без запуска, см. [Командная строка](/ru/docs/reference/cli/#start-with-the-install-command).

## Запуск droidpier напрямую

<!-- verify: phase 3 -->

После установки можно пользоваться и командой `droidpier`. `droidpier start` запускает шлюз в фоновом режиме, как и команда установки. Просто `droidpier` запускает его в окне Терминала до нажатия `Ctrl+C`:

```sh
droidpier start
```

Если оболочка сообщает `command not found`, значит `~/.local/bin` нет в вашем `PATH`. В этом случае скрипт установки выводит подсказку. Добавьте его, например в `~/.zshrc`:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Затем откройте новое окно Терминала и попробуйте снова.

## Обновление

<!-- verify: phase 3 -->

Выполните ту же команду ещё раз. Если есть более новая версия, она заменит файл в `~/.local/bin` и перезапустит шлюз, чтобы заработала новая версия.

<!-- verify: phase 3 -->
Если страница новее вашего шлюза, страница сообщает, что шлюз устарел, и показывает команду для его обновления.
