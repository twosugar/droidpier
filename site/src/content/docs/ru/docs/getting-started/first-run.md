Выполните одну команду в Терминале, откройте `https://droid.devpier.dev/app/` и разрешите доступ к локальной сети, когда Chrome спросит.

## 1. Запустите шлюз

```sh
curl -fsSL https://droid.devpier.dev/install.sh | sh
```

Команда при необходимости устанавливает или обновляет шлюз, а затем запускает его. См. [Установка](/ru/docs/getting-started/install/). После установки шлюз запускает и команда `droidpier start`.

Шлюз работает в фоновом режиме. Окно Терминала можно закрыть.

По умолчанию шлюз слушает `127.0.0.1`, порт `7300`. Чтобы использовать другой порт, см. [Командная строка](/ru/docs/reference/cli/).

## 2. Дайте ему проверить ваш Android SDK {#2-let-it-check-your-android-sdk}

<!-- verify: phase 3 -->
При запуске шлюз проверяет наличие Android SDK, `cmdline-tools`, `emulator`, `platform-tools`, системного образа `system-images;android-34;google_apis;arm64-v8a` и хотя бы одного виртуального устройства (AVD). Если чего-то не хватает, он выводит в Терминале каждый пункт с командой для ручной установки и предлагает завершить настройку на странице. В Терминале он ничего не спрашивает.

Когда шлюз работает в фоновом режиме, этот список попадает в его журнал. Выполните `droidpier logs`, чтобы его увидеть.

<!-- verify: phase 3 -->
Страница показывает тот же список с размером загрузки для каждого пункта:

| Чего не хватает | Что сделать на странице |
|---|---|
| Android SDK, `cmdline-tools`, `emulator`, `platform-tools`, системный образ | Установите пункт кнопкой рядом с ним или установите всё сразу. |
| Нет AVD | Создайте устройство: выберите модель устройства и версию Android. |
| Java, если она нужна какому-то пункту | Установите Android Studio, в которую входит Java, или JDK 17 и новее, затем снова откройте страницу. Java шлюз не устанавливает. |

<!-- verify: phase 3 -->
Ничего не скачивается и не создаётся, пока вы не подтвердите это на странице. Перед началом страница показывает, что будет скачано, куда установлено и сколько места на диске нужно. Во время установки страница показывает каждую лицензию Google полностью, и пункт устанавливается, только если вы согласны. Инструменты командной строки версии 23 и новее могут принимать лицензии без вопроса; страница предупредит об этом до подтверждения.

Например, чтобы установить системный образ вручную:

```sh
sdkmanager "system-images;android-34;google_apis;arm64-v8a"
```

## 3. Откройте страницу {#3-open-the-page}

<!-- verify: phase 3 -->
Откройте `https://droid.devpier.dev/app/` в Chrome или Edge. При запуске шлюз также выводит этот адрес и открывает его в браузере по умолчанию. Если ваш браузер по умолчанию — не Chrome и не Edge, откройте адрес в Chrome или Edge сами.

Страница подключается сама. Пока ни один шлюз не отвечает, она проверяет раз в секунду и подключается, как только шлюз запустится, без перезагрузки. Пока вкладка в фоне, она не проверяет.

Если шлюз работает не на порту `7300`, выведенный им адрес заканчивается на `#port=<port>`:

```text
https://droid.devpier.dev/app/#port=7301
```

Откройте этот адрес, чтобы страница нашла нужный порт.

## 4. Разрешите доступ к локальной сети {#4-allow-local-network-access}

<!-- verify: phase 3 -->
Когда страница впервые подключается к шлюзу на вашем Mac, Chrome показывает запрос разрешения: может ли `droid.devpier.dev` получить доступ к вашей локальной сети. Нажмите **Разрешить**. Chrome запоминает выбор для этого сайта.

Если вы отказали, см. [Устранение неполадок](/ru/docs/guides/troubleshooting/#chrome-blocked-local-network-access).

## 5. Работайте с эмулятором

Если эмулятор с gRPC уже запущен, страница показывает его экран.

<!-- verify: phase 2 -->
Иначе выберите устройство в списке и запустите его. См. [Устройства](/ru/docs/guides/devices/).

Щёлкните по экрану, чтобы передать ему фокус клавиатуры. Затем:

- Щелчок — касание; перетаскивание — свайп.
- Печатайте на клавиатуре Mac. См. [Клавиатура и ввод](/ru/docs/guides/keyboard-and-input/).
- Используйте кнопки «Назад», «Домой» и «Недавние» над экраном.

## Остановка

Выполните `droidpier stop`. Если вы запустили шлюз командой `droidpier` в окне Терминала, нажмите там `Ctrl+C`. Запущенные эмуляторы продолжат работать. При следующем запуске шлюза той же командой или `droidpier start` он снова к ним подключится.

## Локальная резервная страница

Шлюз также сам отдаёт ту же страницу по адресу `http://127.0.0.1:7300/app/` (или на выбранном вами порту). Используйте её, если публичная страница не загружается или не может подключиться.

Чтобы шлюз открывал локальную страницу вместо публичной, запустите его с `--local`:

```sh
droidpier --local
```
