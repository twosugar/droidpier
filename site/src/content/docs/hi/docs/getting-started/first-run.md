Terminal में एक कमांड चलाएँ, `https://droid.devpier.dev/app/` खोलें, और Chrome पूछे तो लोकल नेटवर्क एक्सेस की अनुमति दें।

## 1. गेटवे शुरू करें

```sh
curl -fsSL https://droid.devpier.dev/install.sh | sh
```

ज़रूरत होने पर यह गेटवे को इंस्टॉल या अपडेट करती है, फिर उसे शुरू करती है। [इंस्टॉल](/hi/docs/getting-started/install/) देखें। इंस्टॉल के बाद, `droidpier start` से भी यह शुरू होता है।

गेटवे बैकग्राउंड में चलता है। आप Terminal विंडो बंद कर सकते हैं।

गेटवे डिफ़ॉल्ट रूप से `127.0.0.1` पर, पोर्ट `7300` पर सुनता है। कोई दूसरा पोर्ट इस्तेमाल करने के लिए [कमांड लाइन](/hi/docs/reference/cli/) देखें।

## 2. उसे आपका Android SDK जाँचने दें {#2-let-it-check-your-android-sdk}

<!-- verify: phase 3 -->
शुरू होने पर गेटवे जाँचता है कि Android SDK, `cmdline-tools`, `emulator`, `platform-tools`, सिस्टम इमेज `system-images;android-34;google_apis;arm64-v8a`, और कम से कम एक वर्चुअल डिवाइस (AVD) मौजूद हैं या नहीं। अगर कुछ नहीं है, तो यह Terminal में हर चीज़ को उसे हाथ से इंस्टॉल करने की कमांड के साथ दिखाता है, और सेटअप पेज पर पूरा करने को कहता है। यह Terminal में कुछ नहीं पूछता।

जब गेटवे बैकग्राउंड में चलता है, तो यह सूची उसके लॉग में जाती है। उसे देखने के लिए `droidpier logs` चलाएँ।

<!-- verify: phase 3 -->
पेज पर वही सूची दिखती है, हर चीज़ के डाउनलोड साइज़ के साथ:

| क्या नहीं है | पेज पर आप क्या करते हैं |
|---|---|
| Android SDK, `cmdline-tools`, `emulator`, `platform-tools`, सिस्टम इमेज | किसी एक चीज़ को उसके बगल वाले बटन से इंस्टॉल करें, या सब एक साथ इंस्टॉल करें। |
| कोई AVD नहीं | एक डिवाइस बनाएँ: डिवाइस मॉडल और Android वर्ज़न चुनें। |
| Java, जब किसी चीज़ को इसकी ज़रूरत हो | Android Studio (जिसमें Java शामिल है) या JDK 17 या नया इंस्टॉल करें, फिर पेज दोबारा खोलें। गेटवे Java इंस्टॉल नहीं करता। |

<!-- verify: phase 3 -->
जब तक आप पेज पर पुष्टि नहीं करते, कुछ भी डाउनलोड या बनाया नहीं जाता। शुरू करने से पहले पेज बताता है कि क्या डाउनलोड होगा, कहाँ इंस्टॉल होगा, और कितनी डिस्क जगह चाहिए। इंस्टॉल के दौरान पेज Google का हर लाइसेंस पूरा दिखाता है, और कोई चीज़ तभी इंस्टॉल होती है जब आप सहमति दें। कमांड लाइन टूल्स वर्ज़न 23 या नए बिना पूछे लाइसेंस स्वीकार कर सकते हैं; पुष्टि करने से पहले पेज आपको यह बताता है।

उदाहरण के लिए, सिस्टम इमेज को हाथ से इंस्टॉल करने के लिए:

```sh
sdkmanager "system-images;android-34;google_apis;arm64-v8a"
```

## 3. पेज खोलें {#3-open-the-page}

<!-- verify: phase 3 -->
Chrome या Edge में `https://droid.devpier.dev/app/` खोलें। गेटवे शुरू होने पर यह पता प्रिंट भी करता है और उसे आपके डिफ़ॉल्ट ब्राउज़र में खोलता है। अगर आपका डिफ़ॉल्ट ब्राउज़र Chrome या Edge नहीं है, तो यह पता खुद Chrome या Edge में खोलें।

पेज अपने-आप कनेक्ट हो जाता है। जब तक कोई गेटवे जवाब नहीं देता, पेज हर सेकंड एक बार जाँचता है और गेटवे शुरू होते ही, बिना रीलोड किए, कनेक्ट हो जाता है। टैब बैकग्राउंड में होने पर पेज जाँच नहीं करता।

अगर गेटवे पोर्ट `7300` पर नहीं चल रहा है, तो वह जो पता प्रिंट करता है उसके अंत में `#port=<port>` होता है:

```text
https://droid.devpier.dev/app/#port=7301
```

वह पता खोलें, ताकि पेज सही पोर्ट ढूँढ सके।

## 4. लोकल नेटवर्क एक्सेस की अनुमति दें {#4-allow-local-network-access}

<!-- verify: phase 3 -->
जब पेज पहली बार आपके Mac पर गेटवे से कनेक्ट होता है, तो Chrome एक अनुमति प्रॉम्प्ट दिखाता है जिसमें पूछा जाता है कि क्या `droid.devpier.dev` आपके लोकल नेटवर्क को एक्सेस कर सकता है। **अनुमति दें** पर क्लिक करें। Chrome उस साइट के लिए यह चुनाव याद रखता है।

अगर आपने इसे मना कर दिया था, तो [समस्या निवारण](/hi/docs/guides/troubleshooting/#chrome-blocked-local-network-access) देखें।

## 5. एमुलेटर इस्तेमाल करें

अगर gRPC वाला कोई एमुलेटर पहले से चल रहा है, तो पेज उसकी स्क्रीन दिखाता है।

<!-- verify: phase 2 -->
नहीं तो सूची में से कोई डिवाइस चुनें और उसे शुरू करें। [डिवाइस](/hi/docs/guides/devices/) देखें।

स्क्रीन को कीबोर्ड फ़ोकस देने के लिए उस पर क्लिक करें। फिर:

- टैप के लिए क्लिक करें; स्वाइप के लिए ड्रैग करें।
- अपने Mac के कीबोर्ड पर टाइप करें। [कीबोर्ड और इनपुट](/hi/docs/guides/keyboard-and-input/) देखें।
- स्क्रीन के ऊपर Back, Home और Recents बटन इस्तेमाल करें।

## बंद करें

`droidpier stop` चलाएँ। अगर आपने गेटवे को Terminal विंडो में `droidpier` से शुरू किया था, तो वहीं `Ctrl+C` दबाएँ। चल रहे एमुलेटर चलते रहते हैं। अगली बार जब आप उसी कमांड या `droidpier start` से गेटवे शुरू करेंगे, तो यह उनसे फिर से जुड़ जाएगा।

## लोकल फ़ॉलबैक पेज

गेटवे यही पेज ख़ुद भी `http://127.0.0.1:7300/app/` पर (या आपके चुने हुए पोर्ट पर) सर्व करता है। अगर पब्लिक पेज लोड नहीं होता या कनेक्ट नहीं हो पाता, तो इसका इस्तेमाल करें।

गेटवे से पब्लिक पेज की जगह लोकल पेज खुलवाने के लिए, उसे `--local` के साथ शुरू करें:

```sh
droidpier --local
```
