शुरू करने के दो चरण हैं:

1. नीचे दी गई कमांड Terminal में चलाएँ और विंडो खुली रखें। यह Droidpier इंस्टॉल करके उसे शुरू कर देती है।
2. `https://droid.devpier.dev/app/` खोलें। पेज अपने-आप कनेक्ट हो जाता है। पहली बार, जब Chrome पूछे कि क्या पेज आपके लोकल नेटवर्क को एक्सेस कर सकता है, तो **अनुमति दें** पर क्लिक करें।

चरण 2 [पहली बार चलाना](/hi/docs/getting-started/first-run/) में बताया गया है।

<!-- verify: phase 3 -->
`droidpier` कमांड ही गेटवे है: एक ही executable फ़ाइल जो आपके Mac पर चल रहे Android एमुलेटर को ब्राउज़र पेज से जोड़ती है। इसे चलाने के लिए आपको Node.js की ज़रूरत नहीं है।

## कमांड चलाएँ

<!-- verify: phase 3 -->

पहले [ज़रूरतें](/hi/docs/getting-started/requirements/) जाँच लें। फिर इसे Terminal में चलाएँ:

<!-- 待第 3 阶段 Task 5 确认 -->
```sh
curl -fsSL https://droid.devpier.dev/install.sh | sh
```

पहली बार यह स्क्रिप्ट:

1. Apple Silicon पर macOS के लिए गेटवे, `droidpier-darwin-arm64.tar.xz`, `https://droid.devpier.dev/download/` से डाउनलोड करती है। इसका checksum इसके बगल में, `droidpier-darwin-arm64.tar.xz.sha256` में है।
2. डाउनलोड की गई फ़ाइल को checksum से मिलाती है। अगर दोनों मेल नहीं खाते, तो यह रुक जाती है और कुछ भी इंस्टॉल नहीं करती।
3. गेटवे को `~/.local/bin/droidpier` के रूप में सेव करती है और उसे executable बनाती है।
4. गेटवे शुरू करती है।

गेटवे उसी Terminal विंडो में चलता रहता है। पेज इस्तेमाल करते समय विंडो खुली रखें। इसे बंद करने के लिए `Ctrl+C` दबाएँ।

जब आप वही कमांड फिर से चलाते हैं:

- अगर आपकी कॉपी नई है, तो यह डाउनलोड छोड़कर गेटवे शुरू कर देती है।
- अगर नया वर्ज़न उपलब्ध है, तो यह आपकी कॉपी अपडेट करती है, फिर उसे शुरू करती है।
- अगर डाउनलोड साइट तक नहीं पहुँचा जा सकता, तो यह चेतावनी देती है और आपकी पहले से इंस्टॉल कॉपी शुरू कर देती है।
- अगर गेटवे पहले से चल रहा है, तो यह बताती है और पेज खोल देती है। यह दूसरा गेटवे शुरू नहीं करती।

गेटवे को विकल्प देने के लिए, या उसे शुरू किए बिना सिर्फ़ इंस्टॉल करने के लिए, [कमांड लाइन](/hi/docs/reference/cli/#start-with-the-install-command) देखें।

## droidpier सीधे चलाएँ

<!-- verify: phase 3 -->

इंस्टॉल के बाद, आप `droidpier` कमांड से भी गेटवे शुरू कर सकते हैं:

```sh
droidpier
```

अगर आपका shell `command not found` दिखाता है, तो `~/.local/bin` आपके `PATH` में नहीं है। ऐसे में इंस्टॉल स्क्रिप्ट एक सुझाव प्रिंट करती है। इसे जोड़ें, उदाहरण के लिए `~/.zshrc` में:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

फिर एक नई Terminal विंडो खोलें और दोबारा कोशिश करें।

## अपडेट

<!-- verify: phase 3 -->

वही कमांड फिर से चलाएँ। नया वर्ज़न उपलब्ध होने पर यह `~/.local/bin` में मौजूद फ़ाइल को बदल देती है। अगर गेटवे अभी भी चल रहा है, तो पहले उसे `Ctrl+C` से बंद करें, ताकि कमांड नया वर्ज़न शुरू करे।

<!-- verify: phase 3 -->
जब पेज आपके गेटवे से नया होता है, तो पेज आपको बताता है कि गेटवे पुराना हो गया है और उसे अपग्रेड करने की कमांड दिखाता है।

## अगला चरण

[पहली बार चलाना](/hi/docs/getting-started/first-run/): गेटवे को आपका Android SDK जाँचने दें, पेज खोलें, और लोकल नेटवर्क एक्सेस की अनुमति दें।
