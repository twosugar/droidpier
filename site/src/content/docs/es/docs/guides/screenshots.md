## Tomar una captura de pantalla

Haz clic en el botón de captura de pantalla que está sobre la pantalla. Tu navegador descarga un archivo PNG.

- La imagen se toma del emulador a la resolución propia del dispositivo, no al tamaño que se muestra en la página. Para un dispositivo de 1080×2340, el PNG es de 1080×2340.
- El archivo se llama `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, por ejemplo `screenshot-Pixel_5_API_34-20261111-153000.png`.
- El archivo se guarda en la carpeta de descargas de tu navegador.
