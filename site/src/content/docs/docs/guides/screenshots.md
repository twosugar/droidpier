## Take a screenshot

Click the screenshot button above the screen. Your browser downloads a PNG file.

- The image is taken from the emulator at the device's own resolution, not the size shown in the page. For a 1080×2340 device the PNG is 1080×2340.
- The file is named `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, for example `screenshot-Pixel_5_API_34-20261111-153000.png`.
- The file goes to your browser's download folder.
