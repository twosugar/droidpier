ページは `droid.devpier.dev` から提供されますが、エミュレーターとゲートウェイはあなたの Mac 上で動いています。開いているウェブページが Mac 上のプログラムに接続しようとする可能性があるため、ゲートウェイはすべての接続を確認します。

## ループバックのみ

ゲートウェイは `127.0.0.1` のみをリッスンします。ローカルネットワークやインターネットからの接続は受け付けません。他のコンピューターからはアクセスできません。

## オリジン許可リスト

<!-- verify: phase 3 -->
ページが WebSocket を開くとき、ブラウザは `Origin` ヘッダーを送信します。ウェブページはこれを偽装できません。ゲートウェイは `droid.devpier.dev` 上の公開ページと、ゲートウェイ自身のローカルページからの接続のみを受け付けます。つまり、次のオリジンのみです。

- `https://droid.devpier.dev`
- `http://127.0.0.1:<port>`
- `http://localhost:<port>`

<!-- verify: phase 3 -->
リスト外のオリジンまたはオリジンなしの接続はコード `4003` で閉じられます。ポートを推測されても、他のサイトのページはエミュレーターを制御できません。

## ページがゲートウェイを見つける仕組み

<!-- verify: phase 3 -->
- 応答するゲートウェイがない間、`droid.devpier.dev/app/` のページは 1 秒ごとにゲートウェイを確認し、`droidpier` が起動するとすぐに接続します。タブがバックグラウンドにある間は確認しません。
- ページはポート `7300`、またはアドレスの `#port=` の後のポートを使用します。ゲートウェイは、ポート `7300` 以外で動いている場合にのみ、開くアドレスに `#port=<port>` を付けます。
- ページはポートをブラウザに保存しません。

## ウェブサイトはあなたの Mac に接続しない

<!-- verify: phase 3 -->
Chrome のローカルネットワーク許可とゲートウェイのオリジンチェックは、パスではなくサイト単位で機能します。そのため、ドキュメントページは `/app/` のエミュレーターページと許可を共有します。その影響を限定するために：

- `/app/` のエミュレーターページのみがゲートウェイに接続します。ホームページとこれらのドキュメントページは接続しないため、閲覧しても許可プロンプトは表示されません。
- このサイトはサードパーティのスクリプト・スタイル・フォント・メディアを読み込みません。すべてのコンテンツは `droid.devpier.dev` から提供されます。

## ソフトウェアのインストール

<!-- verify: phase 3 -->
ゲートウェイが確認なしに Android SDK パッケージをインストールしたり、デバイスを作成したりすることはありません。インストールやデバイスの作成は、ダウンロードする内容と保存先がページに表示されたあと、ページで確認します。Google のライセンスはページに全文表示され、同意した項目だけがインストールされます。バージョン 23 以降のコマンドラインツールは確認なしでライセンスに同意することがあり、その場合は確認の前にページが知らせます。ゲートウェイはターミナルで質問しません。

## 接続クローズコード

<!-- verify: phase 3 -->
| コード | 意味 |
|---|---|
| `4000` | 最初のメッセージが `hello` でなかった。 |
| `4002` | ページとゲートウェイのプロトコルバージョンが異なる。 |
| `4003` | オリジンが許可されていない。 |
