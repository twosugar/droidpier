## Mac からエミュレーターへ

<!-- verify: phase 2 -->
Mac でテキストをコピーします。エミュレーターの画面をクリックしてから Cmd+V を押します。

- ASCII テキストは 1 文字ずつエミュレーターに入力されます。
- 他の文字（日本語・絵文字など）を含むテキストは、エミュレーターのクリップボードに入れられてペーストされます。これによりエミュレーターのクリップボードの内容が置き換わります。

## エミュレーターから Mac へ

<!-- verify: phase 2 -->
Android 内でテキストをコピーします（例：長押しして「コピー」を選択）。ゲートウェイはエミュレーターのクリップボードを監視し、新しいテキストをページに送ります。ページはそれを Mac のクリップボードに書き込み、Mac 上の任意の場所で Cmd+V でペーストできます。

<!-- verify: phase 2 -->
ブラウザはページがフォーカスを持っているときのみクリップボードへの書き込みを許可します。別のウィンドウが前面にある場合など書き込みが失敗すると、ページに通知が表示されます。クリックするとテキストをコピーできます。

## 非 ASCII テキストの入力

macOS のインプットメソッドで日本語などの非 ASCII テキストを入力する場合も、エミュレーターのクリップボードを経由します。[キーボードと入力](/ja/docs/guides/keyboard-and-input/#chinese-and-other-non-ascii-text)を参照してください。
