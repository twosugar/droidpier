## スクリーンショットを撮る

画面上部のスクリーンショットボタンをクリックします。ブラウザが PNG ファイルをダウンロードします。

- 画像はページに表示されているサイズではなく、デバイス自身の解像度でエミュレーターから取得されます。1080×2340 のデバイスでは PNG は 1080×2340 になります。
- ファイル名は `screenshot-<AVD 名>-<yyyyMMdd-HHmmss>.png`、例として `screenshot-Pixel_5_API_34-20261111-153000.png` となります。
- ファイルはブラウザのダウンロードフォルダに保存されます。
