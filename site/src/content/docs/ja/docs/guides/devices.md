ここでいうデバイスとは、Mac 上の Android 仮想デバイス（AVD）のことです。ページは一度に 1 つのデバイスを表示します。

## デバイスリスト

<!-- verify: phase 2 -->
左側のリストには、`emulator -list-avds` が報告するすべての AVD が表示されます。各項目には次の情報が表示されます。

- 名前；
- 画面解像度；
- Android バージョン；
- 状態：未起動・起動中（経過秒数付き）・起動済み・起動済みだが引き継ぎ不可；
- 起動または停止ボタン。

<!-- verify: phase 2 -->
解像度・RAM・Android バージョンは、`~/.android/avd/<name>.avd/` の各 AVD の `config.ini` から取得します。`ANDROID_AVD_HOME` を設定している場合、ゲートウェイはそのディレクトリを読み込みます。`config.ini` にフィールドが存在しない場合は空白になります。

## デバイスを起動する

<!-- verify: phase 2 -->
デバイスの横にある起動ボタンをクリックします。ゲートウェイは次のコマンドを実行します。

```sh
emulator -avd <name> -no-window -grpc <port> -no-boot-anim -gpu host
```

- `-no-window` は独立したエミュレーターウィンドウを開かないことを意味します。画面はページにのみ表示されます。
- gRPC ポートは `8554` から始まる最初の空き偶数ポートです。
- `adb -s emulator-<serial> shell getprop sys.boot_completed` が `1` を返したとき、デバイスは起動済みと見なされます。それまでページに進捗が表示されます。
- 180 秒以内に起動しない場合、起動は失敗し、ゲートウェイはエミュレータープロセスを終了します。

<!-- verify: phase 2 -->
デバイスの起動中に再度起動ボタンをクリックしても、2 つ目のコピーは起動しません。起動中にページを閉じて再度開いた場合、進捗は続きます。

## デバイスを停止する

<!-- verify: phase 2 -->
停止ボタンをクリックします。ゲートウェイは `adb -s emulator-<serial> emu kill` を実行します。

## すでに起動中のエミュレーター

ゲートウェイは、エミュレーターが `~/Library/Caches/TemporaryItems/avd/running/` に書き込むファイルを通じて起動中のエミュレーターを検出します。gRPC が有効なエミュレーター（例：`-grpc <port>` で起動したもの）が動いている場合、ゲートウェイは別のコピーを起動せずにそれに接続します。

<!-- verify: phase 2 -->
gRPC なしで起動しているエミュレーターは「起動済みだが引き継ぎ不可」と表示されます。ゲートウェイが画面を読み取って入力を送るには gRPC が必要です。そのエミュレーターを停止し、ページから起動し直してください。

## ゲートウェイを停止したとき

ゲートウェイを停止してもエミュレーターは停止しません。次回ゲートウェイを起動すると、再び接続されます。

## デバイスを作成する

<!-- verify: phase 3 -->
デバイスはページで作成します。新規デバイスのボタンを使い、デバイスのモデルと Android のバージョンを選んで、名前を付けます（ページが候補を出します）。実行前に、ページはモデル、Android のバージョン、割り当てるメモリを表示します。そのバージョンのシステムイメージがまだない場合は、確認して Google のライセンスに同意したあと、ゲートウェイがダウンロードします。

デバイスの作成にはコマンドラインツール（`avdmanager`）が必要です。ない場合は、ダイアログが先にインストールを案内します。[初回起動](/ja/docs/getting-started/first-run/#2-let-it-check-your-android-sdk)を参照してください。

`avdmanager` や Android Studio でデバイスを作成することもできます。一覧に自動で表示されます。

## デバイスを削除する

デバイスの横にあるゴミ箱アイコンをクリックして確認します。デバイスとそのすべてのデータ（インストールしたアプリ、ファイル、スナップショット）が削除され、元に戻せません。システムイメージは削除されません。実行中または起動中のデバイスは削除できません。先に停止してください。
