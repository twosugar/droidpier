## マウスとトラックパッド

- **タップ：** 画面をクリックします。
- **スワイプ：** 押す・ドラッグ・離す。ゲートウェイはこの動きを 1 回のタッチとしてエミュレーターに送ります。
- 画面の端を越えてドラッグし、画面外で離した場合でも、エミュレーターはリリースイベントを受け取るため、タッチが押しっぱなしになることはありません。

ページ座標はページのサイズを考慮してデバイスのピクセルに変換されます。

<!-- verify: phase 2 -->
デバイスを回転させると、変換に新しい向きが使用されるため、クリックした位置にタップが届きます。

## スクロールホイール

<!-- verify: phase 2 -->
エミュレーターにはスクロールホイール入力がないため、ページがホイールの動きを短いスワイプに変換します。

- ホイール 100 ピクセルの動きがデバイス上の 300 ピクセルのスワイプになります（1 回のスワイプは最大 900 ピクセル）。
- スワイプの方向はホイールとは逆になります。下にスクロールすると指が上に動く（スマートフォンと同じ）。
- 50 ms 以内のホイールイベントは 1 回のスワイプにまとめられます。

## キーボード

まず画面をクリックしてキーボードフォーカスを与えます。

- 印刷可能な文字とファンクションキー（矢印・Enter・Backspace・Tab・Escape など）は押した瞬間にエミュレーターに送られます。
- Cmd を使うブラウザショートカット（Cmd+R・Cmd+W など）はキャプチャされず、ブラウザに対して機能します。

<!-- verify: phase 2 -->
Cmd+V で Mac の内容をペーストします。[クリップボード](/ja/docs/guides/clipboard/)を参照してください。

## 日本語などの非 ASCII テキスト {#chinese-and-other-non-ascii-text}

macOS の任意のインプットメソッドで入力します。インプットメソッドが単語の変換を確定すると、ページは次の処理を行います。

1. テキストをエミュレーターのクリップボードに入れる；
2. エミュレーターにペーストを送る。

エミュレーターにインプットメソッドアプリはインストールされません。トレードオフとして、この操作でエミュレーターのクリップボードが上書きされます。

エミュレーターのキー入力は非 ASCII 文字を落とすため、このようなテキストはクリップボード経由で送られます。

## デバイスボタン

画面上部のボタン：

| ボタン | 送るもの |
|---|---|
| 戻る | `GoBack` |
| ホーム | `GoHome` |
| 履歴 | `AppSwitch` |

<!-- verify: phase 2 -->
| ボタン | 操作 |
|---|---|
| 回転 | デバイスを時計回りに 90° 回転 |
| 音量アップ / ダウン | `AudioVolumeUp` / `AudioVolumeDown` |
| 電源 | `Power`；もう一度押すと画面が点灯 |
| スクリーンショット | PNG をダウンロード。[スクリーンショット](/ja/docs/guides/screenshots/)を参照 |
