## Fazer uma captura de tela

Clique no botão de captura de tela acima da tela. Seu navegador baixa um arquivo PNG.

- A imagem é capturada do emulador na resolução nativa do dispositivo, não no tamanho exibido na página. Para um dispositivo de 1080×2340, o PNG tem 1080×2340.
- O arquivo se chama `screenshot-<AVD name>-<yyyyMMdd-HHmmss>.png`, por exemplo `screenshot-Pixel_5_API_34-20261111-153000.png`.
- O arquivo vai para a pasta de downloads do seu navegador.
